# Security policy

## Supported versions

The latest release on the default branch receives security fixes while the project remains experimental.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not open a public issue containing credentials, private memories, transcripts, or exploit payloads derived from real user data.

Include:

- affected version or commit;
- minimal synthetic reproduction;
- expected and actual behavior;
- impact;
- suggested mitigation, if known.

## Scope

Security-sensitive areas include outbound data boundaries, prompt-injection containment, source allowlists, timeout/cancellation behavior, audit privacy, and accidental addition of memory-write capabilities.
